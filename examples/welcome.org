* Make yourself at home
Org is plain text with a little structure. Headings begin with stars,
links keep their labels close, and a list is just a list. It works in
Emacs, in your favorite editor, and on the back of an envelope.

This is *org-preview*: a live reader for your =.org= files. Open a file,
keep writing in your editor, and watch this page follow along when you save.

#+begin_quote
The file is yours. The editor is your choice.
#+end_quote

* Code stays code
Source blocks are displayed as text. They never run.

#+begin_src emacs-lisp
(defun a-little-room-to-think ()
  "Start with an empty buffer."
  (switch-to-buffer (get-buffer-create "notes.org"))
  (org-mode))
#+end_src

* Bring your own notebook
Use the Open file button, drop an =.org= file onto this window, or launch
from the terminal with a file path. Edit it elsewhere and save. The preview
keeps its scroll position as your document changes.

#+begin_src sh
npm run dev -- ~/notes/today.org
#+end_src

This is the first prototype. Local images, links to other Org files, math
rendering, and full Emacs export compatibility are still ahead of us.
